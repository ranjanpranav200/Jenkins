What is Continuous Integration?

Continuous Integration (CI) is a development practice where developers integrate code into a shared repositiry frequently, preferably sereval time a day.


Each Integration can then be verified by an automated build and automated test (unit test)

It will build and test automatically every time when someone pushes new code into the source repositiry (Git Hub)


Code -> Biuld -> Integrate -> Test -> Release -> Deploy -> Moniotor


Benefits ->

i) Integration time gap is relatively much lesser
ii) Relatively lesser risk or changs in conflicts


Importance of CI :

Improve quality :- 
                   Improve quality by running multiple unit test and analyzing various sttics code.


Increase Productivity :- 

                         Automating build of code save a lot of time thereby increasing producivity.

Reduces Risk :-  
						Eliminate the risk of potential human error by automating test.
