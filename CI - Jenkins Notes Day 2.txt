Jenkins Job creation page & types of jobs :-

1. Freestyle Project :- Jenkins provide the option of choosing from differrent type of jobs to build our project.
                        Freestyle biuyld jobs are geneal purpose build jobs which provide maximum flexiblity.
						It can  use for any type of project.
						
2. Pipleline :-  

					this project runs the entire software development workflow as code. Instead of creating several jobs for each stage of software development, 
					we can  now run the entire workflow as one code.
					
						
3. Multi Configuration :- 
							Multiproject allows us to run the same build job on different enviroment. It is used for testing an application
							in  different enviroment.

4. Folder :- This project allows user to create folder to organise and categorise similar jobs in one folder or sub folder.


5. Mutlibranch Pipeline :- 
							This project type let us implement different jenkinsFile or different branch of the same project.
